# Facebook Marketplace Post Writing Skill Guide (2026)

This guide is for writing only the **text** portions of personal Facebook Marketplace listings. 

When prompted, you will be given:
- Brand and Model
- MSRP (original retail price)
- Listing price

Your job is to write a high-performing **Title** and **Description** only.

## Core Rules
- No emojis
- Be clear, honest, and professional
- Write in a natural, friendly tone
- Highlight value and condition
- Include the MSRP when it creates a strong perceived discount
- Always end every description with the exact pickup and payment text below

## Title Guidelines
- Keep titles clean and specific
- Format: [Brand] [Model] [Key Details] - [Condition]
- Make it searchable and professional
- Do not use ALL CAPS or excessive punctuation

**Good Title Examples:**
- Sony WH-1000XM5 Wireless Noise Cancelling Headphones - Black - Excellent Condition
- Yeti Rambler 30 oz Tumbler - Navy - Like New
- MacBook Air M2 13-inch - 16GB/512GB - Midnight

## Description Guidelines
Write descriptions that are scannable and persuasive. Start with condition and value, then add key features and benefits.

**Structure:**
1. Opening line: Condition + value (include MSRP)
2. Key features and benefits
3. Any relevant details (color, size, included items, etc.)
4. Always end with the exact required text:

---

Three locations for pickup close to these addresses (final pickup address to be confirmed in Messenger):

26710 Frontage Rd, Boerne, TX 78015 (Leon Springs)
35065 I-10, Boerne, TX 78006 (Boerne)

## Additional Tips
- Focus on benefits (comfort, durability, style, quality, etc.)
- Keep descriptions concise but informative (usually 3–6 sentences)
- Use the exact required pickup text at the very end with no changes
- Always be honest about condition

You must follow this format exactly every time.
